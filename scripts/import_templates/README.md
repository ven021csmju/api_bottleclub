# นำเข้าข้อมูลจริง (Phase 47)

ไฟล์ในโฟลเดอร์นี้เป็น **แม่แบบ** — เปิดใน Excel / Google Sheets แก้แถวตัวอย่างเป็นข้อมูลจริง แล้ว
**บันทึกเป็น "CSV UTF-8 (คั่นด้วยจุลภาค)"** (Excel: *CSV UTF-8 (Comma delimited)*) ชื่อไฟล์เดิม.
แถวแรกเป็นหัวคอลัมน์ **ห้ามแก้ชื่อหัวคอลัมน์**; ลำดับคอลัมน์สลับได้; แถวว่างทั้งแถวถูกข้าม.
ช่องว่างหน้า/หลังข้อความถูกตัดทิ้งให้อัตโนมัติ. ไฟล์ไหนไม่ใช้ ลบทิ้งได้ (สคริปต์ข้ามไฟล์ที่ไม่มี).

นำเข้าด้วย `scripts/import_master_data.py` (ผ่าน API ด้วยบัญชี Superadmin — ไม่เขียนฐานข้อมูลตรง):

```bash
# 1) ตรวจอย่างเดียว (ค่าเริ่มต้น): ตรวจทุกแถว + บอกว่าจะสร้าง/แก้อะไร — ไม่เขียนอะไรเลย
python3 scripts/import_master_data.py --api https://api.wayneven.uk --dir ~/bottleclub-prod/import --username <superadmin>
# 2) ถ้าผลถูกต้อง: เขียนจริง
python3 scripts/import_master_data.py --api https://api.wayneven.uk --dir ~/bottleclub-prod/import --username <superadmin> --apply
```

- รหัสผ่าน Superadmin ถูกถามตอนรัน (ไม่แสดงบนจอ, ไม่ใส่ในคำสั่ง).
- **ถ้ามีแถวไหนผิดแม้แต่แถวเดียว จะไม่นำเข้าอะไรเลย** — สคริปต์บอกชื่อไฟล์ + เลขแถว (ตามที่เห็นใน Excel: หัวคอลัมน์ = แถว 1) + เหตุผล ของทุกแถวที่ผิด.
- **รันซ้ำได้**: แถวที่มีอยู่แล้ว (จับคู่ด้วย `code` / `name` / `sku` / `username`) จะถูก **แก้ให้ตรงกับไฟล์** ไม่สร้างซ้ำ;
  รันซ้ำด้วยไฟล์เดิม = ไม่มีอะไรเปลี่ยน.
- **ไม่ลบ**: ข้อมูลที่มีในระบบแต่ไม่มีในไฟล์ จะถูกปล่อยไว้ (ลบ/ปิดใช้งานทำในหน้า Admin).
- **ช่องไม่บังคับที่เว้นว่าง**: แถวใหม่ = ค่าเริ่มต้น; แถวที่มีอยู่แล้ว = **ไม่แก้ค่าเดิม** (เว้นว่างไม่ใช่การลบค่า) —
  ยกเว้น `station` ของสินค้า: ว่าง = ตามหมวด.
- ลำดับที่นำเข้า: สาขา → หมวดหมู่ → สินค้า → เครื่องขาย → พนักงาน (ไฟล์หลังอ้างถึงไฟล์ก่อนได้).

## branches.csv — สาขา

| คอลัมน์ | บังคับ | ความหมาย |
|---|---|---|
| `code` | ✔ | รหัสสาขา (ไม่ซ้ำ, ≤ 50 ตัว, ตัวอักษรอังกฤษ/ตัวเลข/`-`/`_`) — ใช้จับคู่ตอนรันซ้ำ และอ้างจากไฟล์อื่น; **แก้รหัสภายหลังไม่ได้** |
| `name` | ✔ | ชื่อสาขา (≤ 255) |
| `phone` | | เบอร์โทร (≤ 50) |
| `address` | | ที่อยู่ |

## categories.csv — หมวดหมู่สินค้า

| คอลัมน์ | บังคับ | ความหมาย |
|---|---|---|
| `name` | ✔ | ชื่อหมวด (ไม่ซ้ำ, ≤ 255) — ใช้จับคู่ตอนรันซ้ำ และอ้างจาก `products.csv` |
| `station` | | จอที่รายการของหมวดนี้ไปขึ้น: `kitchen` (ครัว) / `bar` (บาร์) / `none` (ไม่ขึ้นจอ). ว่าง = `none` |
| `sort_order` | | ลำดับการแสดง (จำนวนเต็ม, น้อยขึ้นก่อน). ว่าง = 0 |
| `description` | | คำอธิบาย |

## products.csv — สินค้า

| คอลัมน์ | บังคับ | ความหมาย |
|---|---|---|
| `sku` | ✔ | รหัสสินค้า (ไม่ซ้ำในไฟล์และในระบบ, ≤ 100) — ใช้จับคู่ตอนรันซ้ำ |
| `name` | ✔ | ชื่อสินค้า (≤ 255) |
| `category` | | ชื่อหมวด — ต้องมีใน `categories.csv` หรือในระบบอยู่แล้ว. ว่าง = ไม่มีหมวด |
| `selling_price` | ✔ | ราคาขาย (บาท) มากกว่า 0, ทศนิยมไม่เกิน 2 ตำแหน่ง เช่น `1250` / `1250.00` / `1,250.00` |
| `cost_price` | | ต้นทุนต่อหน่วย (บาท) ≥ 0, ทศนิยมไม่เกิน 2 ตำแหน่ง — ใช้คิดมูลค่าสต็อกในรายงาน. ว่าง = สินค้าใหม่ 0 / สินค้าเดิมไม่แก้ |
| `unit` | | หน่วยขาย (≤ 20) เช่น `bottle`, `glass`, `plate`. ว่าง = `each` |
| `station` | | ใส่เฉพาะเมื่อสินค้านี้ไปจอต่างจากหมวด: `kitchen` / `bar` / `none`. **ว่าง = ตามหมวด** |
| `barcode` | | บาร์โค้ด (ไม่ซ้ำในไฟล์และในระบบ, ≤ 255). ใส่เป็นข้อความ — ถ้า Excel แสดงเป็น `2E+12` ให้จัดรูปแบบคอลัมน์เป็น "ข้อความ" ก่อนพิมพ์ |

สินค้า**ใหม่**เปิดขายทันทีและนับสต็อก; สินค้าที่ปิดขายไว้แล้วจะไม่ถูกเปิดใหม่ (เปิดในหน้า Admin). **จำนวนสต็อกไม่ได้นำเข้าที่นี่** (รับเข้าผ่านใบสั่งซื้อ/ปรับสต็อก).

## registers.csv — เครื่องขาย (เครื่อง POS / ลิ้นชักเงิน)

| คอลัมน์ | บังคับ | ความหมาย |
|---|---|---|
| `branch` | ✔ | รหัสสาขา (`code` จาก `branches.csv` หรือที่มีในระบบ) |
| `name` | ✔ | ชื่อเครื่อง (≤ 100, ไม่ซ้ำในสาขาเดียวกัน) — สาขา + ชื่อ ใช้จับคู่ตอนรันซ้ำ |

## staff.csv — พนักงาน

| คอลัมน์ | บังคับ | ความหมาย |
|---|---|---|
| `username` | ✔ | ชื่อผู้ใช้สำหรับ login (≤ 100, ไม่ซ้ำ; ตัวอักษรอังกฤษ/ตัวเลข/`.`/`_`/`-`) — ใช้จับคู่ตอนรันซ้ำ |
| `display_name` | ✔ | ชื่อที่แสดง |
| `email` | ✔ | อีเมล (ระบบบังคับ, ไม่ซ้ำ) — ยังไม่มีการส่งอีเมลหาพนักงาน |
| `role` | ✔ | บทบาท: `Manager` (ผู้จัดการสาขา / Branch Admin), `Cashier` (แคชเชียร์), `Kitchen` (ครัว), `Bar` (บาร์). **นำเข้า `Superadmin` ไม่ได้** |
| `branch` | | รหัสสาขาที่ทำงาน. **ว่าง = ทุกสาขา** (เช่นผู้จัดการทุกสาขา) |
| `phone` | | เบอร์โทร (≤ 50) |

- คนเดียวทำหลายสาขา/หลายบทบาท = **หลายแถว username เดียวกัน** (ชื่อ/อีเมล/เบอร์ต้องตรงกันทุกแถว).
- **ไม่มีคอลัมน์รหัสผ่าน**: ระบบสุ่มรหัสชั่วคราวให้พนักงานใหม่ (ต้องเปลี่ยนตอน login ครั้งแรก, **หมดอายุใน 72 ชั่วโมง** —
  หมดแล้วให้ผู้จัดการกด "reset รหัส"). สคริปต์เขียนรหัสลงไฟล์สิทธิ์ 600 ใน home (ชื่อไฟล์บอกตอนจบ) — **ไม่แสดงบนจอ**;
  แจกให้พนักงานแล้ว **ลบไฟล์ทิ้ง**. พนักงานที่มีอยู่แล้ว: ไม่เปลี่ยนรหัส.
- รันซ้ำ: แก้ชื่อ/อีเมล/เบอร์ให้ตรงไฟล์ และ **เพิ่ม** บทบาทที่ยังไม่มี; บทบาทที่มีในระบบแต่ไม่มีในไฟล์ **ไม่ถูกถอด**
  (สคริปต์แจ้งเตือน — ถอดในหน้า Admin).
